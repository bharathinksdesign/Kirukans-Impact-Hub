Use the hero's dark navy-purple as the consistent dark brand color rather than introducing alternative dark purples.

**Why:** The user explicitly said the background color used in the hero is the right dark color and asked to use the same.

**How to apply:** Keep new dark sections consistent with the hero, except the black footer. The header is white. This does not mean converting all light sections to dark.

Do not add a yellow divider below the header. Keep the header logo prominent.

**Why:** The user explicitly repeated the request to remove the header's yellow line and asked for a larger logo.

**How to apply:** Keep the header free of a yellow divider and preserve the prominent logo and mild shadow.

Use a white header with dark navy text, distinct from the dark hero.

**Why:** After asking to distinguish the top bar from the hero, the user explicitly said “make the top bar white.”

**How to apply:** Preserve the hero's approved navy, white header and dark navigation text. Retain subtle separation without a yellow divider.

Use white instead of cream/off-white for the website's light surfaces.

**Why:** The user provided the cream background swatch and asked to change that color in the website to white.

**How to apply:** Keep light sections and cards white rather than restoring the cream from earlier design references. Leave the dark hero, yellow and teal brand colors unchanged.

Use black for the footer background.

**Why:** The user asked to change the footer background to black.

**How to apply:** This is a footer-only exception; retain the navy-purple hero and white header.
