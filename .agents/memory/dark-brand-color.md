name: Brand colors
description: User-approved dark and light surface colors for Kirukans.
---

Use only the user's supplied eight-swatch palette for website interface colours.

**Why:** The user corrected the newly introduced gold and darker teal and said “pls use the provided colors only all over the website.”

**How to apply:** Use the shared palette for headings, backgrounds, controls, forms and error states. For contrast, choose another approved colour rather than inventing a darker shade. Preserve the original colours in actual photos, logos and supplied artwork.

Convert colour-profiled swatch screenshots to sRGB before sampling.

**Why:** The supplied screenshot had an embedded display profile; copying its raw pixel values produced different colours from its visible swatches.

**How to apply:** Use profile-aware conversion when comparing or extracting new reference colours. Do not treat raw RGB samples as web hex values without checking the image profile.

Use the existing navy-purple as the consistent dark brand colour rather than introducing alternative dark purples.

**Why:** The user approved the original hero navy as the dark brand colour, then later changed the homepage hero itself to light grey.

**How to apply:** Retain the navy brand colour for dark sections and text, except the black footer. The header is white and the homepage hero is light grey.

Do not add a yellow divider below the header. Keep the header logo prominent.

**Why:** The user explicitly repeated the request to remove the header's yellow line and asked for a larger logo.

**How to apply:** Keep the header free of a yellow divider or elevation shadow and preserve the prominent logo. The user later explicitly removed the yellow shadow from the top bar alone; keep the subtle neutral border and leave button/card hover shadows unchanged.

Use the palette's light neutral for the header with dark navy text.

**Why:** After asking to distinguish the top bar from the hero, the user explicitly said “make the top bar white.”

**How to apply:** Preserve a light header and dark navigation text using approved palette colours. Retain subtle separation without a yellow divider.

Use the supplied light neutral instead of warm cream for light surfaces.

**Why:** The user first replaced warm cream with white, then restricted the website to the supplied palette, which includes a cool light neutral.

**How to apply:** Keep light sections, cards and the homepage hero in the supplied cool neutral rather than restoring warm cream or introducing a new neutral.

Use black for the footer background.

**Why:** The user asked to change the footer background to black.

**How to apply:** Use the supplied black for the footer; retain the light header and homepage hero.

Use light grey for the homepage hero, with dark text for readability.

**Why:** The user asked to make the hero light grey and supplied a grey reference swatch, replacing the earlier dark hero choice.

**How to apply:** Preserve the existing hero copy, calls to action and right-hand image. Do not recolour other navy sections or story-page heroes without a separate request.

Keep main filled CTAs visually stable on hover: retain their readable brand fill/text pairing and use restrained lift, shadow and icon movement rather than swapping to unrelated fills.

**Why:** The user called the CTA hover states bad; the previous yellow hero CTA faded into the light surface, and other main actions flipped to teal.

**How to apply:** Preserve contrast and recognisability in hover states. Keep disabled controls still and respect reduced motion.

Use pure white for the homepage “Who we are” section, as a scoped exception to the cool-neutral surfaces.

**Why:** The user explicitly asked for this section's background to be white after selecting the palette.

**How to apply:** Make this section white edge to edge; do not change the light-grey hero or other sections as part of this exception.

Use the supplied teal for a slim social/contact strip above the light navigation bar.

**Why:** The user requested a cyan-coloured strip above the top bar with social icons, phone and Gmail, following their reference.

**How to apply:** Keep the strip separate from the light navigation surface and use readable dark icons/text. Do not invent unverified social profile destinations.

Keep the mobile contact strip on one line, showing phone and email icons instead of their full text.

**Why:** The user explicitly asked to hide the full number and email in mobile view and show only icons on one line.

**How to apply:** Keep social, phone and email icons together on mobile; retain clickable contact links and accessible names. Desktop still shows the full contact text.

Use crisp, solid yellow offset shadows only on hover across the website, not soft blurred or persistent resting shadows.

**Why:** The user supplied the Create card as the reference, then clarified “the shadows should only come while we hover not all the time.”

**How to apply:** Use approved yellow, a bottom-right offset and zero blur only while hovered by a hover-capable pointer; cards use navy outlines. Resting and selected states have no visible elevation. Scale the offset down for small controls; preserve keyboard focus rings and reduced-motion behaviour.

Yellow buttons use the approved dark violet shadow on hover instead of yellow.

**Why:** The user explicitly asked “for buttons which are yellow make the dark violet color shadow.”

**How to apply:** Apply the contrasting violet shadow to yellow-filled actions, including those becoming yellow on hover. Keep the hover-only rule; other surfaces retain yellow shadows.
